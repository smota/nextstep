# Nextstep 2.1.0

Nextstep 2.1.0 brings optional applicant guidance, evidence-aware artifact reviews, and submission reconciliation to the local career command engine.

## Highlights

- Resolve consequential gaps through optional guidance and scoped briefs, while keeping research, drafting, networking, and applications independently usable.
- Review application artifacts against grounded criteria and audience needs, including recruiter-scan and keyword-grounding support.
- Record incomplete submission reports without inventing dates, channels, or transmitted artifacts. Reconcile later evidence while preserving the original report and historical artifact bytes.
- Inspect the opportunity pipeline through a read-only portfolio projection.
- Use a native candidate profile when Holoself context is unavailable, without duplicating Holoself-managed context.
- Distribute the five Nextstep skills through Skills Manager, with deterministic packaging, drift checks, and verified library hashes.

## Version and compatibility

This is a minor bump from the existing product version 2.0.0 to 2.1.0. It is the first published GitHub Release; the previous repository tag is v1.3.0. The intervening history includes the earlier transition to the v2 opportunity graph and local CLI, so v1 users must review the current architecture and data-layout documentation before adopting it. Legacy commands and the former application/server model are not supported.

Node.js 20 or newer is required. Download the tagged source or check out v2.1.0 and follow the README. This release is distributed through GitHub; the package remains private for npm publication.
