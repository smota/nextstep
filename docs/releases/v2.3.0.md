# Nextstep 2.3.0

Find local Master guides directly from the CLI with current source paths and hashes.

## Changes

- `master catalog` lists current local Markdown paths, titles, sizes and SHA-256 values.
- `master query --query <terms>` performs explicit literal token matching and returns bounded excerpts with provenance, match counts and exclusions.
- Retrieval excludes Archive directories, hidden entries, links and non-Markdown files. It rejects escaping paths, file changes, invalid UTF-8 and oversized corpora. File-handle identity checks protect the read boundary; normalized search offsets map back to original source text.
- Domain query policy is separate from filesystem access. There is no persistent index, server, embedding service or Holoself domain indexing. Existing `context build` behavior is unchanged.
- Portable skill references describe the new commands. GitHub Actions now validates the CLI on Windows, Ubuntu and macOS with Node 20 and 24.

## Validation and distribution

Local Windows validation on Node 26.10.0: `npm test` passed 166 tests with one optional Skills Manager test skipped; `npm run check`, `npm run skills:package` and diff checks passed. The pull request and main workflow provide the exact remote matrix results.

Node 20 or newer is required. This is an additive minor release from 2.2.0, distributed through GitHub; the npm package remains private. Private data migrations and machine-specific environment configuration are outside the release artifact.

Publication, merge and local installation were authorized by the owner in the coordinated closure plan on 2026-10-04.
