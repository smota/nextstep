# Nextstep 2.2.0

Nextstep delegates personal context lens selection to Holoself and makes its data-root boundaries explicit.

## Changes

- Query Holoself with `--self-only`, without a default or forwarded `--lens`. Preserve the lens returned by Holoself, including project-specific resolution.
- Preserve native candidate-profile fallback when Holoself is unavailable, and surface other Holoself failures instead of hiding them.
- Clarify that Nextstep indexes registered relational entities and artifacts. Local `Master/` guides remain directly readable by external clients; there is no generic full-text index over them.
- Describe artifact review perspectives separately from Holoself personal lenses. Existing `lens` and `lenses` review schema fields remain unchanged.
- Include the previously merged data-root changes in PR #11: stop reading `NEXTSTEP_DATA_ROOT`, `NEXTSTEP_STATE_ROOT`, and `NEXTSTEP_HOLOSELF_HOME`; allow read-only root resolution from the current directory and require an explicit vault for mutations.

## Compatibility and distribution

This owner-requested minor release increments 2.1.0 to 2.2.0. Callers using the retired `NEXTSTEP_*` variables must use explicit CLI options or supported project markers; consult [CLI root resolution](../cli.md). Holoself owns its environment and project binding.

Node.js 20 or newer is required. Distribution is through GitHub; the npm package remains private. Private vault migrations and personal backlog material are excluded.
